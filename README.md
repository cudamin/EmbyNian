# EmbyNian

Emby 4.9.x 的 Windows 桌面客户端，**只做影视**——电影和剧集。播放交给随程序附带的 mpv：直连服务器上的原始文件，不经服务器转码，画面在客户端窗口里渲染，并按放大倍数自动挂一套着色器。

- **不转码**，永远拉原始流（`Static=true`），画质就是文件本身的画质
- **内置播放内核**，装好就能播，不需要另外装 mpv，也不读 `mpv.conf` / `input.conf`
- **画质自动挡**：按「放大倍数 × 真人或动画 × 显卡档」挑一条着色器链，每一档都做 4:2:0 色度重建
- **播放进度、续播位置和「看过」标记**与 Emby 双向同步
- 六套主题、自绘标题栏、零过渡零动画的界面

界面只有中文，当前版本 0.0.1。

## 系统要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 1809 及以上；实际只在 Windows 11 上验证过 |
| 架构 | 仅 x64，没有 ARM64 版本 |
| 运行时 | 发行版自包含，**不需要**预先安装 .NET 10 或 Windows App SDK |
| 服务器 | Emby 4.9.x |
| 可选 | 「服务器控制台」那一页需要 WebView2 Runtime；没有它只是这一页提示改用浏览器打开，其余功能照常 |

发行版是一个解压即用的目录（非打包 exe），没有安装程序，也没有自动更新或检查新版本。

## 上手

1. 解压后运行 `EmbyNian.exe`。
2. 登录页填服务器地址、用户名和密码。也可以让它按 Emby 的 UDP 7359 广播发现局域网里的服务器，或者从服务器公开的用户列表里直接挑人。
3. 密码和访问令牌用 Windows 帐户密钥（DPAPI）加密后保存，只能在当前 Windows 帐户下解开。
4. 多台服务器、多个账号都能存下来。侧栏底部有切换服务器、切换用户和注销。

## 浏览

**首页**顶部是一条大图轮播，它站在下面几排的头几个条目上，不额外问服务器一次。下面是「继续观看」「媒体库」「接下来看」「最近添加」，再往下每个媒体库各一排——排哪几排、什么顺序，在设置里拖着改。

**横向卡片带**没有底部滚动条：指针移上去，两端浮出翻页箭头，一次翻整整一屏卡片，正好落在下一张卡的左边沿。指针停在卡片上不会把页面的竖向滚动抢走（横向滚轮要按住 Shift）。

**卡片**上，指针移过去时封面正中央浮出圆形播放键（能播的条目才有），底边一颗小药丸放已观看、收藏和「更多」。媒体库那种卡片只留「更多」——一个媒体库既谈不上看过也收藏不了。用键盘的话，这四样都在卡片自己的右键菜单里（`Shift+F10`）。

**媒体库页**有三种视图（海报 / 缩略图 / 列表）、排序、字母跳转和分页；筛选是二十来个开关，加上类型、标签、年份三张由服务器给值的表。**搜索**覆盖电影、剧集、单集和未识别的视频。**合集**能浏览、能新建、能把条目加进去。详情页的演职人员点开是这个人的参演作品。

## 详情页

照 Emby 网页端的样子排：条目自己的剧照虚化压暗铺在头部当背景，左上角一张 16:9 剧照，右边是剧名、`S1:E5 - 集名`、评分徽标加首播日期、时长、分级，然后是 `视频： 4K · HEVC · MKV` 一行和音频、字幕、媒体源三个下拉。

按钮一排：播放（或「继续播放 12:00」）、从头开始、标记已看、收藏、在网页端打开、更多。简介默认截到四行。

下面是「更多来自：第一季」和「演职人员」两条卡片带。季下拉换一季之后，卡片、标题和播放按钮一起跟着换；默认打开的是第一个还没看完的编号季（整部剧看完了就是第一季），带「特辑」的剧不会开在特辑上。

## 播放

画面直接在客户端窗口里渲染，不弹外部窗口；也可以在设置里切回外部 `mpv.exe`（命名管道 IPC）。

**浮层**是单层的（Emby / YouTube 那种）：顶栏放返回、标题、统计和关闭；底栏顶边是整宽进度条，左边一排走带加时钟，右边是倍速、选集、音轨、字幕、设置、全屏；音量是画面右侧竖着的一条。浮层**按指针位置直接显示或收起，不做淡入淡出**——越靠近画面下沿底栏越清晰，指针停在画面正中间时全部收起，那里正是字幕的位置。静止 650 毫秒自动隐藏，暂停、缓冲和菜单开着时常驻。

- **进度条**带章节刻度、拖动时的时间气泡和 Emby 的章节缩略图；窗口化时浮层收起后底边留一条细进度线，全屏不留
- **统计面板**（顶栏那颗按钮）每秒刷新一次：位置、倍速、缓存与缓存速度、音视频同步、编码、分辨率、帧率、码率、像素格式、硬件解码、视频输出、丢帧、声道与采样率，读不到的项目直接不显示
- **跳过片头片尾**：先认章节名（`OP`/`ED`/`片头`/`片尾`/`前情提要`/`オープニング` 等），认不出名字时只认最外侧那几个章节里长 80–100 秒、且落在开头 200 秒或结尾 300 秒内的一段。走进区间后右下角浮出按钮，底边一条随播放位置排空的倒计时线，15 秒不理会就收回；可以改成自动跳过或彻底关闭
- **上一集 / 下一集和一集播完的自动连播都跨季**：第一季最后一集之后接的是第二季第一集，「选集」跟着换成新那一季；集号带缺口或某一季只有一集也照样接得上
- **窗口跟着画面的形状缩放**：拖左右边自动配高度，拖上下边自动配宽度，所以既不裁切也不留黑边
- **右键画面菜单**八组：导航、画面、视频、视频滤镜、截屏、音频、字幕、片段循环
- **截图**三种：屏上这一帧（带字幕和着色器）、原始画面（都不带）、按窗口尺寸；文件名是片名加时间码
- 每次播放都是新起的一个 mpv，并且用 `--no-config` 启动：`mpv.conf` 和 `input.conf` 一律不读，参数全部由设置页和内置基线给出。因此右键菜单里改的东西不存盘，能跨片子活下来的是设置里有的那些

## 画质：着色器档位

着色器随程序打包，不需要自己去下载或指路。

选哪一条链看**放大倍数**——实际渲染出来的尺寸除以片源尺寸，也就是画面真正被铺开的倍数。四档：缩小（<1.05）、微放大（1.05–1.45）、甜点（1.45–2.2）、大倍数（>2.2）。再乘上「真人 / 动画」得到八格，每格按显卡档位（低 / 中 / 高，装机默认低档）换一条链。

- **每一格都做色度重建**（CfL）——4:2:0 的片源里色度只有亮度的一半分辨率，这是性价比最高的一项
- **片源有多烂是另一根轴**：高度不超过 576 线的（DVD 那一代）在链的最前面加去色带，中高档再加轻度降噪，可以单独关掉
- **高帧率片源降级**：超过 30 fps 时动画那一行让出 CNN 放大器改用 ravu，否则一帧的预算装不下
- **窗口尺寸变化跟得上**：开播时按当前窗口和全屏各算一套，进退全屏直接换预备好的那一套；拖窗口时停稳 400 毫秒才判一次，只有跨档才重新加载，边界带回差所以拖过分界不会来回换
- 八档都能手动钉住，播放过程中随时切换；开播时日志和播放器的「播放信息」里各写一行当前是哪一档、挂了哪几个文件

打包的是 ArtCNN、ravu、CfL、SSimDownscaler / SSimSuperRes、adaptive-sharpen、hdeband 和 nlmeans——15 个文件，各自的上游地址和许可写在 `assets/shaders/README.md`。

## 声音

- **输出设备可以选**，列表从 mpv 那儿实读；设置文件里指到一个已经拔掉的设备时，那一行会单独标出来并回落到默认设备，而不是变成没声音
- **音量能到 130%**（mpv 的默认上限），而且记在设置里——换一集或换一部片子还是上次那个值
- **音量均衡**三档：不启用、连续跟随（`dynaudnorm`，夜里看合适）、对齐到固定响度（`loudnorm`，一集接一集合适）。这一项跨编码都有效
- **5.1 下混到两声道时归一化**：治「对白太小声、爆炸太大声」，默认关着，因为代价是整体变轻
- **动态范围压缩**只对带 DRC 信息的 AC-3 / E-AC-3 有效，设置里那一行自己就这么写着——其它编码请用上面的音量均衡
- 还有音频独占模式、全局延迟、扬声器布局、音轨语言优先级，以及 AC3 / EAC3 / DTS / DTS-HD / TrueHD 五个直通开关

## 字幕

语言写成优先级列表（「日语 > 粤语 > 英语」这样），显示模式四档，没有匹配语言时可以回落到默认字幕。

字体从这台机器装的**所有**字体族里挑：带搜索，每一行用它自己那个字体画出来，中文字体同时显示它自己的中文名。字号、加粗、文字颜色、描边大小和颜色、阴影、背景颜色和透明度、编码、把图形字幕拉伸到画面，都在设置里。播放中可以用 `Z` / `Shift+Z` 微调延迟。

服务器上的外挂字幕会作为轨道加载；服务器装了字幕插件的话，还能从客户端搜字幕、下载和删除。

## 界面

六套主题，五深一浅：墨绿（默认）、纯黑（给 OLED）、午夜、石墨、紫夜、晴昼。在设置里点一块色板即时生效。

**没有淡入淡出，没有过渡动画**，这是刻意的。海报不带圆角，结构靠 1px 发丝线而不是色块。标题字用 Bahnschrift SemiCondensed，数字一律等宽。

标题栏是自绘的 32 像素高，前进和后退两支箭头做在里面（`Alt+←` / `Alt+→` 同样能走），走不动的那支只是变暗而不消失。其余可调的还有：锁定窗口比例、默认收起侧边栏、每页条目数、海报宽度、图片缓存上限、显示观看状态标记，以及评分来源——豆瓣、TMDB 和公众分在 Emby 里是同一个数，所以这三档换的是标签，只有烂番茄真的换了一个数。

触摸能用：点一下暂停，双击全屏，长按出菜单。方向键和 `Home` / `End` / `PageUp` / `PageDown` 在卡片带上能走。

## 下载

原始文件直接下载，不转码，一次一个排队，进度报在提示条上。落点是「视频\EmbyNian」，整部剧或整季会下进子文件夹。目录写死，不能取消也不能断点续传。

## 数据存在哪

都在 `%LOCALAPPDATA%\EmbyNian`：设置（`settings.json` 带一份备份，损坏时隔离并回落到默认）、日志（界面里的「诊断」页看的是同一份）、海报缓存、截图。设置页的「关于」卡里，这四个位置各有一颗「打开」按钮。

设置页最下面还有一张「恢复默认」卡，把上面每一张卡里的设置一次改回装机时的样子（按下之后先问一次）。**它不碰服务器、账号和登录状态**，也不碰那些程序替你记着的东西：窗口上次的位置和大小、各媒体库各自的排序筛选和视图、播放器上次的音量。

## 还没做的

这是个自用的客户端，缺口都是真的，列在这儿免得你装完才发现：

- **音乐、有声书、图片**：音乐库整个不进导航栏和首页——宁可不做，也不做半个。照片库能列出缩略图，但点开一张是空的
- **直播电视、录制、节目单**：完全没有
- **不转码**：永远直连原始流。带宽不够，或者这个文件 mpv 认不了，都没有退路——服务器不会替它重新压一遍
- **播放列表和播放队列**：没有。「上一集 / 下一集」走的是 Emby 的季，不是队列
- **本机文件**：打不开本地视频，也不能从本机加载 `.srt` / `.ass`——整个程序里没有文件选择器
- **人物页**：点开演员只有参演作品网格，没有简介和大照片。合集点开也只是一格网格，没有专门的详情页
- **打分**：只显示服务器上的分（可以选看哪一家的），设不了喜欢 / 不喜欢
- **SyncPlay 和遥控**：只往服务器上报「在播什么」，收不到别的客户端发来的控制
- **迷你播放器、画中画、后台播放**：都没有，离开播放页就停（有窗口置顶）
- **键盘可达性**：首页卡片上那四颗按钮只在指针移过去时出现，键盘到不了；替代路径是卡片自己的右键菜单（`Shift+F10`）
- **手柄**：一行代码都没有。方向键和遥控器在卡片带上能走
- 界面**只有中文**；截图**没有快捷键**，只在右键菜单里；**没有自动更新**；只有 **x64**

## 刻意不做的

这些不是忘了，是想过之后决定不做，写清理由免得反复提：

- **刷新率自动切换（24p 输出）**：mpv 自己做不到，得去调 Windows 的显示模式 API。而在开发这台机器上 144 ÷ 24 = 6，整除，没有节拍要补
- **均衡器**：对一个看片客户端价值很低
- **耳机虚拟环绕（HRTF）**：要给程序装一份来历和许可都得交代的 SOFA 资产
- **着色器强度可调**：不是没做，是做不到——`adaptive-sharpen` 的强度是编译期常量，mpv 没有对应的运行时选项
- **自己加载 `.glsl` 组一条链**：现在八个档位是代码里的数据。要做就得有用户着色器目录、链编辑界面，还有一套「用户自己组的链也要过互斥校验」的规则；不做半个
- **显卡档自动检测**：不打算引入显卡型号表。将来要自动就做「持续掉帧降一档」
- **过渡动画**：全应用零动画是设计选择，浮层按指针位置直接显示或收起

## 许可

随程序打包的着色器和 `vulkan-1.dll` 各有各的上游许可，逐个文件列在 `assets/shaders/README.md` 和 `assets/mpv-runtime/README.md` 里（MIT、LGPL-3.0、LGPL-2.1、BSD-2、Apache-2.0）。播放内核用的是 mpv 的 `libmpv`，许可见 mpv 上游。本仓库自身还没有声明许可。
