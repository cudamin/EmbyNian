# EmbyNian

Emby 4.9.x 的 Windows 桌面客户端，只做影视——电影和剧集。播放交给随程序附带的 mpv：直连服务器上的原始文件，不经服务器转码，画面直接渲染在客户端窗口里。

- **不转码**：永远拉原始流，画质就是文件本身的画质
- **内置播放内核**：装好就能播，不需要另外装 mpv，也不读 `mpv.conf` / `input.conf`
- **着色器档位**：按「放大倍数 × 真人/动画 × 显卡档」自动挂一条链，每档都做 4:2:0 色度重建（默认关，设置里开）
- **双向同步**：播放进度、续播位置、「看过」标记与 Emby 同步
- 六套主题、自绘标题栏、零过渡零动画；界面只有中文

当前版本 0.0.1。

## 系统要求

- Windows 10 1809 及以上，仅 x64（只在 Windows 11 上验证过）
- 发行版自包含运行时，解压即用；没有安装程序，也没有自动更新
- 服务器：Emby 4.9.x
- 可选：「服务器控制台」页需要 WebView2 Runtime，没有则提示改用浏览器打开

## 上手

解压后运行 `EmbyNian.exe`，登录页填服务器地址、用户名和密码；也可以按 Emby 的 UDP 广播自动发现局域网服务器，或从服务器的公开用户列表里直接挑人。密码和令牌用 Windows 帐户密钥（DPAPI）加密保存，支持多服务器、多账号。

## 功能

- **首页**：第一屏左边大图轮播、右边一条竖着的「继续观看」（勾掉这一栏则大图铺满）；下面是「媒体库」「接下来看」「最近添加」等横排，排布顺序在设置里拖
- **浏览**：媒体库页三种视图（海报 / 缩略图 / 列表）加排序、筛选、字母跳转和分页；搜索覆盖电影、剧集、单集和未识别视频；合集能浏览、新建、添加条目；详情页照 Emby 网页端排，季下拉换季，演职人员点开是参演作品
- **播放**：内嵌渲染（也可切外部 mpv.exe）；浮层按指针位置直接显示或收起，不做淡入淡出；进度条带章节刻度和缩略图；统计面板每秒刷新；跳过片头片尾（认章节名，可自动跳过或关闭）；上一集 / 下一集和一集播完的自动连播都跨季；窗口拖边按画面形状配尺寸，不裁切不留黑边；右键画面菜单八组；三种截图（带字幕和着色器的当前帧 / 原始画面 / 按窗口尺寸）
- **画质**：着色器随程序打包（ArtCNN、ravu、CfL、SSimDownscaler 等 15 个文件），按放大倍数分四档 × 真人/动画 × 显卡档，每一档都做色度重建；DVD 代片源自动加去色带和降噪；超过 30 fps 自动让出 CNN 放大器；mpv 自带的 `fast` / `high-quality` 预设不受开关影响
- **声音**：输出设备可选、音量上限 130%、音量均衡三档（连续跟随 / 对齐固定响度）、5.1 下混归一化、AC-3/E-AC-3 动态范围压缩、五种音频直通开关、音频独占模式
- **字幕**：语言写成优先级列表、显示模式四档、从全系统字体里挑（带搜索和实时预览）、服务器外挂字幕作轨道加载，装了字幕插件还能搜索、下载、删除
- **下载**：原始文件直接下载，一次一个排队，落点「视频\EmbyNian」

## 快捷键

播放时：

| 按键 | 作用 |
| --- | --- |
| 空格 / `←` `→` / `↑` `↓` | 播放暂停 / 快退快进 / 音量 ±5 |
| `F` / `Esc` / `M` / `T` | 全屏 / 退出 / 静音 / 窗口置顶 |
| `P` / `N` | 上一集 / 下一集（跨季） |
| `PageUp` / `PageDown` | 上一章节 / 下一章节 |
| `[` `]` / `Backspace` | 倍速 ±0.1 / 回到 1.0 |
| `Z` / `X`（加 `Shift` 反向） | 字幕 / 音频延迟 ±0.1 秒 |
| `Y` | 确认跳过片头 / 片尾 |

浏览时 `Alt+←` / `Alt+→` 前进后退，卡片上 `Shift+F10` 出右键菜单。鼠标：滚轮调音量，单击暂停，双击全屏，拖浮层顶栏移动窗口。触摸：点一下暂停，双击全屏，长按出菜单。

## 数据

都在 `%LOCALAPPDATA%\EmbyNian`：设置（损坏自动隔离并回落默认）、日志、海报缓存、截图。设置页有「恢复默认」，不碰服务器、账号和程序替你记的东西（窗口位置、各库排序、上次音量）。

## 没做的

自用客户端，缺口是真的：音乐 / 有声书 / 图片、直播电视、播放列表、本地文件和本地字幕、人物详情页、打分、SyncPlay、手柄、自动更新；只有 x64，界面只有中文。

另有几件是刻意不做的：24p 输出、均衡器、耳机虚拟环绕、着色器强度可调、用户自组着色器链、显卡档自动检测、过渡动画——想过之后决定不做。

## 许可与开发

打包的着色器和 `vulkan-1.dll` 各有上游许可，逐文件列在 `assets/shaders/README.md` 和 `assets/mpv-runtime/README.md`；播放内核是 mpv 的 libmpv。本仓库自身尚未声明许可。

架构、构建、发布与 `--self-check` 自检见 [`docs/开发与验证.md`](docs/开发与验证.md)，规矩在 [`CLAUDE.md`](CLAUDE.md)，在途工作在 [`PROGRESS.md`](PROGRESS.md)。
