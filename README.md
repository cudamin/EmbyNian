# EmbyNian

面向 Emby 4.9.x 的现代化 Windows 桌面客户端，基于 .NET 10 WinUI 3，用 mpv 播放原始视频流。
Core 与测试项目不引用 NuGet；WinUI 3 外壳按需引用 Windows App SDK 的子包（`Microsoft.WindowsAppSDK.Base`
等六个，不用那个把十个子包裹在一起的 `Microsoft.WindowsAppSDK` 总包），从 nuget.org 还原。

## 功能

- 使用 Emby 用户名和密码登录，记住多个服务器与账号，可从服务器的公开用户列表里挑人；登录页和服务器管理页支持通过 Emby UDP 7359 广播发现局域网服务器
- 密码和访问令牌都用 Windows 帐户密钥（DPAPI）加密后保存，只能在当前 Windows 帐户下解开
- 首页分区展示「继续观看」「接下来播放」「媒体库」「最近添加」，海报墙浏览媒体库、目录、剧集与搜索结果；每条横向卡片带没有底部滚动条，指针移上去时两端浮出翻页箭头，一次翻整整一屏卡片，正好落在下一张卡的左边沿
- 指针移到一张卡片上，封面正中央浮出圆形播放键（能播的条目才有：剧集、文件夹、人物只能点开），底边一颗小药丸放已观看、收藏和「更多」；媒体库那种卡片只留「更多」—— 一个媒体库既谈不上看过也收藏不了，右键菜单同样不列这两条
- 详情页照 Emby 网页端的样子排：条目自己的剧照虚化、压暗铺在头部当背景，左上角一张 16:9 圆角剧照，右边是剧名、`S1:E5 - 集名`、红底评分徽标加首播日期/时长/分级，然后是 `视频： 4K · HEVC · MKV` 一行和音频/字幕/媒体源三个圆角下拉；下面一排圆角按钮（播放或「继续播放 12:00」、从头开始、标记已看、收藏、网页端、更多），简介默认截到四行，展开靠「阅读更多」；再往下是「更多来自：第一季」和「演职人员」两条横向卡片带 —— 单集卡点正中央的播放键直接播，点别处进那一集的页面，人物卡点开就拿名字去搜。整页可以竖向滚动，横向卡片带只在按住 Shift 时接滚轮，所以指针停在卡片上不会把页面滚动抢走；要看后面的卡片按带子两端浮出的翻页箭头。剧集页的「更多来自」那条带子上方有一个季下拉，换一季之后卡片、标题和播放按钮一起跟着换；默认打开的是第一个还有没看完的编号季（整部剧看完了就是第一季），带「特辑」的剧不会开在特辑上 —— 它排在最前面，却几乎不是想接着看的那一季
- 内置 libmpv 播放：`libmpv-2.dll` 直接渲染在客户端窗口里，无需外部窗口；也可以在设置里切回外部 `mpv.exe`（命名管道 IPC）
- 播放界面是单层浮层（Emby / YouTube 风）：顶栏放返回、标题、统计信息与关闭，底栏顶边是整宽进度条，左边一排走带（播放/暂停、上一集、下一集）加时钟，右边是倍速、选集、音轨、字幕、设置、全屏；音量是画面右侧竖着的一条，落在右边缘的正中间，禁音按钮就在它下方
- 浮层按指针位置直接显示或收起，不使用淡入淡出：越靠近画面下沿底栏越清晰，越靠近上沿顶栏越清晰，指针停在画面中间时都收起来 —— 那里正是字幕的位置。音量条只在指针移到右侧区域或滚轮调音量时出现。静止 650 毫秒后自动隐藏；指针停在浮层上、菜单开着、暂停和缓冲时常驻，键盘操作则不论指针在哪都会亮一次
- 播放时不显示窗口标题栏和页面头部，画面直接铺满窗口，只留浮层顶栏（拖它可以移动窗口）；窗口边框保留，可以照常缩放
- 缩放窗口时按画面比例联动：拖左右边自动配高度，拖上下边自动配宽度，所以画面既不被裁切也不留黑边（比例取自 mpv 的 `dwidth`/`dheight`）；想手动裁切填充仍可用右键菜单 → 画面 → 「开 / 关 裁切填充」
- 片头片尾一键跳过，规则照搬随附 mpv 配置里的 `chapterskip.lua`：先按章节名认（`OP`/`ED`/`片头`/`片尾`/`Preview`/`前情提要`/`オープニング` 等），认不出名字时只认最外侧那几个章节里长 80–100 秒、且落在开头 200 秒或结尾 300 秒内的一段 —— 所以没有名字的 90 秒章节算片头，4 分钟的不算，完全没有章节的文件不猜。位置和名字冲突时以位置为准：十分钟处的「OP」是标错的章节，前半段的「ED」不是片尾。相邻的同类区间会合成一次跳跃（前情提要接着 OP 就只按一次）。开始播放一两秒后客户端会拿 mpv 自己的 `chapter-list` 替换 Emby 的章节表 —— 后者通常是十分钟一格的无名缩略图，前者才是压制组写了「OP」的那份；因为决定是按时间点记的，换表不会把已经回答过的又问一遍
- 走进区间后右下角浮出「跳过片头」/「跳过片尾」按钮，按钮底边有一条随播放位置排空的倒计时线，15 秒不理会就自动收回（不理会本身就是回答）；点一下或按 `Y` 直接跳到区间末尾，并在画面上报一句「已跳过片头: 0:00-1:30」。「设置 → 播放行为 → 跳过片头片尾」可以改成自动跳过或彻底关闭；自动模式只在刚进入区间的两秒内跳，所以手动拖到片尾中间不会被甩出去，而跳到文件结尾的区间会留半秒让 mpv 自己收尾
- 顶栏的「统计」按钮打开客户端自绘的播放统计面板：位置、倍速、缓存与缓存速度、音视频同步、编码、分辨率、帧率、码率、像素格式、硬件解码、视频输出、丢帧、声道与采样率，每秒刷新一次，读不到的项目直接不显示
- 进度条带章节刻度、拖动时的时间气泡与 Emby 章节缩略图；窗口化时浮层收起后底边留一条细进度线（全屏不留，那时屏幕上只该有画面）
- 倍速 0.5×–2.0×、上一集/下一集、章节前后跳、字幕与音频延迟微调（±0.1 s），都能用键盘操作：`[` `]` 调速、`Backspace` 复位、`PgUp` `PgDn` 跳章节、`P` 上一集、`N` 下一集、`Z` / `Shift+Z` 字幕延迟、`X` / `Shift+X` 音频延迟、`Y` 接受跳过片头片尾的提示；`空格` 播放/暂停、`←` `→` 前后 10 秒、`↑` `↓` 音量 ±5、`F` 全屏、`Esc` 退出全屏或返回，滚轮划过音量条同样能调音量。音量记在设置里，换一集或换一部片子还是上次那个值 —— 每次播放都是新起的 mpv 且它自己的配置被挡掉，不记下来就一律回到 100。「上一集 / 下一集」和一集播完的自动连播都跨得过季边界：第一季最后一集之后接的是第二季第一集，跨过去之后「选集」跟着换成新那一季 —— 走的是服务端按季再按集排好的整部剧列表，所以集号带缺口（比如第一季从 10 直接跳到 12）或者某一季只有一集也照样接得上
- 在画面上右键唤出画面菜单：导航、宽高比与旋转缩放、去色带与反交错、解码方式、HDR 映射、声道与音量均衡、字幕位置字号、视频滤镜、片段循环等，取自随附 mpv 配置里的菜单
- 着色器配置组：按分辨率和「动画」判定自动挑选配置组，播放过程中也能随时切换
- 播放进度上报、续播位置与「看过」标记同 Emby 双向同步
- 自绘深色界面、侧边栏导航、PerMonitorV2 DPI；前进/后退两支箭头做在标题栏里（和 Claude 桌面版同一个位置：商标右边一行扁扁的图标按钮），走不动的那支只是变暗而不消失（`Alt+←` / `Alt+→` 同样能走），层级面包屑单独一行、只在真有上级时才占位置；设置页提供常用 mpv 参数的下拉框、开关和滑块，字幕字体从这台机器装的所有字体族里挑（直接读 `C:\Windows\Fonts` 和用户字体目录里每个字体文件的名字表，带搜索，每一行用它自己那个字体画出来，中文字体同时显示它自己的中文名），并能在“配置文件”分类中查看/编辑/备份 `mpv.conf` 与 `input.conf`（保留原编码和行结构）。播放启动使用 `--no-config` / `config=no`，因此这些文件编辑不会覆盖客户端专用播放参数；内置播放器的按键由客户端自己处理（libmpv 用 `input-default-bindings=no` 启动），`input.conf` 同时作为右键画面菜单的来源
- 诊断模式 `--self-check`（可加 `--dump-ui`）与 `smoke.ps1` 冒烟脚本

## 架构

解决方案是 `EmbyNian.sln`，三个项目：

- `src/EmbyNian.Core`：Emby 访问层、设置与凭据保险箱、mpv 配置读写，以及两个播放后端 —— 内置的 `LibMpvBackend` 和外部进程的 `MpvProcessBackend`。刻意不引用桌面 UI 与 `System.Drawing`，所以能在纯控制台里测。
- `src/EmbyNian.Shell`：当前 WinUI 3 外壳 —— 登录、主页、媒体库、搜索、详情页、设置、服务器管理、诊断与播放界面。
- `tests/EmbyNian.Tests`：手写的离线测试宿主，`dotnet run` 本身就是 runner，不用任何 NuGet 包。

第一代单项目源码（`MainForm.cs`、`MediaLibraryView.cs`、`ConfigEditorView.cs`、`UiTheme.cs`、`EmbyApiClient.cs` 等）曾经放在 `legacy/v1/` 供参考，2026-09-02 从工作树里删掉了：它不参与构建、也没有任何代码引用，而 git 历史里那一份是完整的（`git log -- legacy/v1` 找得到，`git show <提交>:legacy/v1/MainForm.cs` 读得出）。留在工作树里只会让人以为它还在这套东西里占着位置。

## 构建与运行

`global.json` 钉住了 SDK 版本。如果机器上装了多个 .NET SDK，`PATH` 里的 `dotnet` 不一定是那一个——
装了系统级 8.x 和用户级 10.x 的机器上，`PATH` 找到的是 8.x，然后每条命令都会以「找不到与 global.json
匹配的 SDK」失败。这种情况下把下面的 `dotnet` 换成那个装了 .NET 10 SDK 的完整路径，通常是
`$env:USERPROFILE\.dotnet\dotnet.exe`。（`tools\publish.ps1` 自己会挑，不用管。）

```powershell
dotnet build .\EmbyNian.sln -m:1
```

```powershell
dotnet run --project .\src\EmbyNian.Shell\EmbyNian.Shell.csproj
```

跑测试：

```powershell
dotnet run --project .\tests\EmbyNian.Tests\EmbyNian.Tests.csproj
```

发布发行版（自包含目录并打成 ZIP）：

```powershell
.\tools\publish.ps1
```

脚本默认发布 WinUI Shell 的 Windows App SDK 自包含版本到 `artifacts\publish\win-x64`，并生成
`artifacts\EmbyNian-3.0.0-win-x64.zip`。发布后会自动把着色器包、mpv 依赖 dll 和
`libmpv-2.dll` 一起复制到输出目录，内置播放器不再依赖外部 mpv 安装。需要 MSIX 时可传
`-Msix`；脚本会在 Windows SDK 找到 `makeappx.exe` 时生成未签名的
`artifacts\EmbyNian-3.0.0-win-x64.msix`，否则明确报出安装 SDK 的提示。

改完代码只是要一个能跑的 exe 时传 `-NoArchive`：跳过打包那一步，同一次发布从一两分钟降到二十来秒
（323 MB 压成 126 MB 的 zip 就是那一两分钟）。上一次的 zip 照旧先删 —— 一个跟刚发布的目录对不上的
压缩包比没有压缩包更坏。交付前照旧不带这个开关：那个 zip 才是交出去的东西。

发布需要仓库根目录的匹配版 `libmpv-2.dll`，以及 `C:\mpv_config-2026.08.12\portable_config\shaders`；
配置不在该路径时用 `-MpvRoot <目录>` 指定包含 `portable_config\shaders` 的目录。

默认 ZIP 是带 Windows App SDK 原生运行时的自包含非打包 WinUI 3 应用，目标机器仍需要 WebView2 Runtime；
使用 `-FrameworkDependent` 时 ZIP 更小，但目标机器需要预先安装 .NET 10 Desktop Runtime 和 Windows App SDK。
MSIX 仍需用受信任证书签名后才能安装。

在自己这台机器上顺手放一个桌面快捷方式，传 `-Shortcut`；也可以单独跑：

```powershell
.\tools\shortcut.ps1
```

它写的是桌面上的 `EmbyNian.lnk`，指向 `artifacts\publish\win-x64\EmbyNian.exe`，图标取自 exe，
工作目录设成 exe 所在目录。`-Exe <路径>` 可以指向别的构建（比如调试输出），`-Remove` 删掉它。
发布默认不写桌面 —— 那是这台机器的事，不是构建的事。

## 自检与冒烟

`--self-check` 不显示窗口，逐个构建、布局并绘制每个页面、播放顶栏、音量竖条、跳过片头片尾按钮、播放统计面板与控制栏的每个浮层，同时检查 mpv 路径、配置文件、着色器配置组是否还对得上。除了「画出来不报错」，还有十几项专门盯行为和几何：「显隐规则」把指针依次摆到画面下沿、右边缘、正中间，再滚一次滚轮、静止 650 毫秒、停在进度条上，逐种情形核对该出现的浮层出现了、不该出现的没出现，「显隐规则已复位」接着确认一个控件都没留在屏上；「底边细线只在窗口化」验证浮层收起后窗口化留细进度线、全屏不留；「章节预览定位」拿一根 1138 像素宽的进度条在三处取预览，核对气泡不会越出画面、有缩略图时是画面（168 高）没有时只剩文字（45 高），并且浮层收起后它也跟着消失；「设置分类走查」把 8 张卡片逐个打开数出 67 个行容器，「设置行模板」再从视觉树上数一遍必须还是 67 —— 八套模板里任何一个坏掉的资源键都只表现为「那一行没了」，编译一声不响；「字幕字体列表」往字体搜索框里真打字，最关键的一条是搜一个任何机器上都不存在的名字之后，当前字体必须还留在列表里（能被过滤掉的值也能让这一行看起来没设置），顺带给四次全量过滤计时；「画面比例联动」核对 16:9 确实交给了窗口（客户区 1264×711 = 1.778）且归零能解除；「全屏几何」拉满 2560×1440 量覆盖、去边框、置顶和退出还原，「全屏时的任务栏」再问一句任务栏中点上盖着的是不是本窗口；「拖动标题栏移动窗口」按住标题栏走 37,23 像素，核对窗口跟着走、尺寸不变、松手后不再跟随、全屏时不接受拖动；「标题栏前进后退」把箭头的每种状态都摆一遍量位置（两头都走不动时两支都还站着、只是暗下来，面包屑那一行整行收起），核对整组箭头确实落在 32 像素高的标题栏里，再拿 `WM_NCHITTEST` 问窗口：两支箭头那块必须是客户区（否则按下去变成拖窗口），它两边和商标那块必须还答「标题栏」，而且在播放标题栏来回切过一轮之后依然如此 —— 撤回一次分区声明（`ClearRegionRects` 或空数组）会让整条带子永久变成客户区，看完一部片回来就拖不动窗口了；「系统按钮点得动」把框架自己报的右侧留白等分三格，逐格问 `WM_NCHITTEST`，必须分别答最小化、最大化、关闭按钮 —— 在这条带子上声明区域会盖掉框架给那三颗按钮报的位置，按钮照画照高亮、却只剩一张图，「播放时右上角归页面」再反过来问同一三格，播放时必须都答客户区，因为那时候画在那儿的是浮层自己的窗口按钮；「卡片悬浮按钮」把首页真卡片上的悬浮层亮起来量一遍：可播放卡片的圆形播放键中心必须压在封面中心上（差一个逻辑像素都算，截图上看「差不多在中间」是看不出来的），媒体库卡片必须一个已观看/收藏都没有、只剩「更多」；最后两条要连着真服务器才问得出来，它们各自证的那句话没有任何本地夹具能替代 ——「跨季相邻单集」在服务器上挑一部真的多季剧，用整部剧的单集列表找出一个季边界，断言从季末走一步正好落在下一季第一集、退回来又是原来那一集，再把交给「选集」的那一季列表跟服务端单独按季返回的列表逐个 id 比一遍（跨得过去靠的是服务端 `ParentIndexNumber,IndexNumber,SortName` 这个顺序，不是本地算集号），「详情页季切换」另建一个不上屏的详情页视图模型换一季，断言卡片、标题和播放目标都跟着走 —— 标题要单独断言，因为它来自 `EpisodeScope` 而不是来自卡片，集子对了、季名错了的页面否则会混过去；这两条遇上没登录、这台服务器上没有可走的季边界或往返出错时报「信息」而不是失败。报告写在
`%LOCALAPPDATA%\EmbyNian\logs\selfcheck-shell.txt`，全部通过返回 0，有问题返回 1。

```powershell
.\EmbyNian.exe --self-check
```

加上 `--dump-ui` 会多写两份东西到 `%LOCALAPPDATA%\EmbyNian\logs`：`selfcheck-shell.png` 是自检走完最后
一页时那一帧的界面截图，`selfcheck-shell-tree.txt` 是同一时刻的可视化树。整套页面的截图不在这里 ——
自检自己只留一张，逐页拍照是 `tools\shot.ps1` 的活。

```powershell
.\EmbyNian.exe --self-check --dump-ui
```

这台机器上保存过账号时，自检会等它自己登录回来，再拿真实的媒体库把每个页面走一遍，那张截图和报告里的读数
也就都是真实内容；没有保存账号时它停在登录页，「详情页排版」那一关改用一个样例条目自己填。样例刻意不带图片
tag，图片仓库只会去取有 tag 的图，所以那一关里虚化背景和卡片剧照仍然是占位图。

`--theme <id>` 让这一次运行换一套主题（`--theme daylight`，也接受 `--theme=daylight`），认不出来的 id
回落到默认那套。**它只改这一次运行看到的颜色，不写设置文件** —— 六套配色里换主题的唯一入口是设置页上点一
块色板，而「晴昼」是唯一的浅色，浅色主题下才会露出来的毛病（没登记进 `ThemeHost` 的画刷、系统自己画的那
块标题栏）本来只能靠手点才看得见。配合 `tools\shot.ps1` 就是一条命令一张照片：

```powershell
.\tools\shot.ps1 -Exe artifacts\publish\win-x64\EmbyNian.exe -Out shots\daylight.png -ExeArgs "--theme daylight --show-settings" -WindowTitle 设置
```

自检不会替你输密码，只认已经保存下来的账号。让程序真跑一段时间的活交给冒烟脚本：启动一段时间后报告进程是否还活着，并打印本次运行的日志。

```powershell
.\smoke.ps1
```

```powershell
.\smoke.ps1 -Release
```

## 数据与路径

数据目录是 `%LOCALAPPDATA%\EmbyNian`：

- `settings.json`（schema v5）与 `settings.backup.json`；文件损坏时会被隔离并回退到默认设置，读取永不抛异常
- `logs\app-yyyyMMdd.log` 运行日志，界面里的「诊断」页看的是同一份内容（内存里保留最近 500 条）
- `cache\images` 海报与缩略图缓存

首次启动在登录页填写 Emby 地址、用户名和密码；外部 mpv 可执行文件路径在「设置 → 播放器」里改，配置文件路径在「设置 → 配置文件」里改（留空会从 mpv.exe 同目录的 `portable_config` 推断）。内置后端使用程序随附的 `libmpv-2.dll`、着色器目录和依赖 dll；配置文件编辑器只负责外部文件的查看、维护和备份。
