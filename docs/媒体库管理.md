# EmbyServer 媒体库管理

入口为 **设置 → EmbyServer → 媒体库**；命令行可用 `--show-settings 媒体库`。页面使用 WinUI 原生控件，通过当前登录身份读取和管理服务器。需要 Emby 管理员权限。

对照基准是当前服务器的 Emby Web 4.10.0.40：`librarysetup/librarytab.js`、`advancedtab.js`、`components/medialibrarycreator`、`medialibraryeditor`、`libraryoptionseditor`、`imageoptionseditor`、`modules/refreshdialog`，以及服务器 OpenAPI。参考下载留在忽略目录 `work/libraries-reference`；产品运行不依赖这些文件。

## 功能对应

| 网页功能 | 原生入口与行为 |
| --- | --- |
| 媒体库列表 | 显示封面、库名、类型、目录和扫描状态；按窗口宽度换列 |
| 新建媒体库 | 电影、电视剧、音乐、有声读物、书籍、游戏、音乐视频、家庭视频和照片、混合内容；默认选项从服务器读取；至少添加一个目录；创建后由服务器扫描 |
| 编辑媒体库与重命名 | 点击卡片或更多菜单；库类型保持创建时的类型；本页使用明确的“保存媒体库”按钮，返回时提示尚未保存的选项 |
| 目录管理 | 浏览服务器文件系统、根目录和网络位置；支持手填路径、共享映射、网络访问用户名与密码；已有目录只能修改映射和凭据；添加与移除立即作用于服务器并触发扫描，与网页行为一致 |
| 移除媒体库 | 明确显示库名并默认取消；调用虚拟媒体库移除接口，保留磁盘文件；系统合集库不提供移除入口 |
| 扫描与取消 | 扫描全部媒体库使用 `RefreshLibrary` 计划任务；显示进度，可取消；单库“扫描媒体库文件”使用网页相同的 `Default` 刷新模式 |
| 刷新元数据 | 搜索缺失元数据、替换全部元数据；独立选择替换图片和视频预览缩略图；有覆盖行为时确认 |
| 元数据与图片 | 语言、国家、自动刷新间隔、占位标题刷新、合集导入、成人元数据、存储格式、本地保存与缓存；提供者按服务器返回列表显示，支持勾选及上下调整优先级 |
| 每种项目类型的图片下载设置 | 按服务器支持的图片类型显示；背景图数量 0～20、最小宽度；主图、标志、横幅等按类型开关 |
| 编辑图片 | 原生图片管理器，浏览现有图片、远程搜索、上传本机图片、选择替换和移除图片 |
| 视频处理 | 多部分与多版本分组、剧集合并、文件夹视图、sample 文件阈值、忽略文件、章节生成、视频预览缩略图、片头检测、恢复播放阈值 |
| 字幕与歌词下载 | 下载器启用与顺序、多语言选择、完美匹配、强制字幕、媒体年龄限制、已有音轨/字幕时跳过、本地保存；根据服务器下载器能力显示 |
| 高级 | 添加日期规则、元数据路径和共享路径、人物元数据读写、外部推荐、默认语言和分级地区 |
| 插件配置 | 提供者有设置入口时，在内嵌服务器网页打开该插件自己的配置页；返回时保留媒体库选项草稿 |

依赖服务器、插件或 Emby Premiere 的能力仍由服务器决定。实时监控也受服务器文件系统支持情况影响。页面不模拟扫描或处理结果。

## 保存与身份

- 保存前读取服务器最新配置，只合并实际修改的字段。递归合并项目类型和图片类型选项，保留未知插件字段、未修改字段和其他客户端的修改。
- 选项保存与改名有独立成功检查。高级页对应服务器配置与 `metadata` 配置，前一份成功、后一份失败时明确报错；重试不重复覆盖已成功的配置。
- 新建请求发送后若结果不明，禁止直接重复创建；返回列表刷新核对结果。
- 页面捕获当前会话；旧卡片、旧菜单、确认窗口、图片编辑回调都不能在切服或离页后借新身份提交。
- 目录密码仅放在 HTTP 正文；Emby 令牌由已有会话放入请求头。插件配置的免登录沿用网页控制台受限来源的凭据注入，不使用带令牌的 URL。

## 验证

`LibraryManagementTests` 覆盖分页、反向代理路径、请求方法与正文、深层配置合并、扫描模式、组合选项、输入边界和权限错误。

`--probe-shell` 的媒体库四项检查使用假身份与假传输，操作真实 WinUI 控件，覆盖列表与两种窗口宽度、内容类型切换、目录选择对话框、新建、重复提交防护、目录增删改、提供者顺序、图片选项、扫描取消、高级设置部分失败、离页与切服取消。图片管理器沿用该探针已有的图片对话框检查。所有这些写入都不接触真实服务器。

真实服务器验证只读取列表和选项、检查页面呈现。创建/删除库、修改目录、保存配置和启动扫描会改变真实服务器状态，不作为无授权的测试步骤。
