# 字幕验证矩阵

## 自动选轨

| 输入组合 | 核验结果 |
| --- | --- |
| 中文字幕偏好＋日语音轨 | 外语模式选择中文字幕 |
| 中文＋其他字幕＋日语音轨 | 加入通配项不能关闭字幕 |
| 默认中文、手选日语、字幕自动 | 按手选日语决定字幕 |
| 默认日语、手选中文、字幕自动 | 按手选中文决定字幕 |
| 显式字幕或明确关闭 | 不被自动策略覆盖 |
| 默认轨不存在、不匹配语言 | 不把任意第一条伪装成默认 |
| 标题优先词命中非默认轨 | 严格默认回退仍用明确默认轨 |
| 字幕语言为空＋回退开关关闭 | 空列表语义应与 UI 一致 |
| 强制模式＋默认非强制轨 | 不回退整轨字幕 |
| 外挂 PGS 最优先，另有可播 SRT | 跳过不可加载轨；UI 禁用并说明 |
| 内封 PGS | 不误用外挂限制 |
| 字幕元数据缺失 | 区分未知与明确关闭 |

## 外观

- SRT：字号、50/100/150/300% 缩放、加粗、描边 0/0.5/10、阴影、三种底板。
- 两行文字长短不同：逐行盒应分别包住每行；整体盒包住所有行。
- 描边 10、阴影留白 0：整体背景盒仍包住描边，不能让 RenderTransform 的描边伸出底板。
- 描边与底板用明显不同的颜色，验证不是同一支颜色被错误复用。
- 底板色空、透明度 0/40/100：预览、生成参数和运行属性一致。
- HEX `#123456`、`#AC5D5D`、`#FE0102` 原样提交；RGB 改一个通道不得漂移其他通道。
- ASS：保留样式、force、strip 的区别与代价明确。
- PGS：字体/颜色无效是格式约束；拉伸与 HDR 亮度分别测，不把接受参数当视觉正确。
- 字号相对窗口的 mpv 单位与预览像素比不混为一谈。

## 生命周期

- 改一次外观：预览刷新、当前播放应用、设置保存三条都执行。
- 设值后改回未指定：实时属性确实恢复，不残留旧值。
- 恢复默认／导入备份：当前字幕更新，设置行与模型一致。
- 保存失败：内存值保留、显示未保存；重试成功才清标记。
- 同窗换片：主可见性、次字幕 sid/可见性/延迟/位置/样式归位。
- 异步应用中换片：旧句柄批次不能写到新片。

## 删除确认

只用假委托测试，不调用真实服务器 DELETE。

1. 点删除后：请求计数 0，显示字幕名/媒体文件/不可撤销警告，焦点在安全操作。
2. 取消／关闭：请求计数仍为 0，字幕仍存在，Touched 未改变。
3. 确认：请求恰好一次；重复点击不重发。
4. 请求失败：保留条目，允许重试，无成功提示。
5. 请求成功：移除目标条目，Touched=true，关闭后触发刷新。

## 技能试用提示

这些是回归用例，不是授权真实播放或服务器修改：

- “审查字幕为什么设了简体＋其他字幕，日语片反而不显示？只审查，最多一个子代理。”
  - 应定位通配项/外语判断，验证当前实现；不自行修改，不登录真实库。
- “修复输入 #123456 被改色，并验证底板透明度。”
  - 应保留 RGB 权威值、测空颜色＋alpha 组合、加载真实控件验证；不要用整数 HSV 反算精确输入。
- “参考 dyphire/mpv-config 给字幕补功能并跑一遍验证。”
  - 应先盘点已存在的 HDR/主次/临时控制，明确扩展范围与依赖；本地自动扫描配置不直接用于 HTTP 流；报告裸内核、GUI 与真实播放覆盖差别。
